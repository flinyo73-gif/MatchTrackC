MATCHTRACK — Android Studio проект
==================================

Что уже есть
------------
- Интерфейс MatchTrack в тёмно-фиолетовом стиле внутри Android WebView.
- Добавление матчей, расчёт K/D, KDA, ADR, история и аналитика.
- Сохранение данных на устройстве через localStorage WebView.
- Баннер Google Mobile Ads с официальными ТЕСТОВЫМИ рекламными ID.
- Запрос формы согласия UMP перед рекламой.

Важно про рекламу и деньги
-------------------------
Сейчас стоят только тестовые рекламные ID Google. Они нужны для проверки интеграции и НЕ приносят доход. Нельзя просто подставить случайный ID и получать деньги.
Для настоящей рекламы владелец/родитель или законный представитель должен оформить и настроить аккаунт Google AdMob, создать приложение и рекламный блок, заменить тестовые ID в AndroidManifest.xml и MainActivity.kt, а также выполнить требования по согласию на рекламу, конфиденциальности и публикации. Пользователю младше 18 лет нельзя обходить возрастные требования аккаунтов и выплат: это нужно делать с участием родителя/опекуна.

Как собрать APK
---------------
В этой среде нет Android SDK и Gradle, поэтому готовый APK здесь не собран. Исходный Android Studio проект находится в этой папке.
1. Установи Android Studio на компьютер с официального сайта developer.android.com/studio.
2. Распакуй проект MatchTrack_Android.zip.
3. В Android Studio выбери Open и открой папку MatchTrack_Android.
4. Дождись Gradle Sync и установки Android SDK Platform 35, если IDE попросит.
5. Для тестовой сборки выбери Build > Build Bundle(s) / APK(s) > Build APK(s).
6. APK обычно появится в app/build/outputs/apk/debug/app-debug.apk.

Альтернатива без установленного Android Studio: в проект добавлен GitHub Actions workflow (.github/workflows/build-apk.yml). Если загрузить проект в свой GitHub-репозиторий, сборку можно запустить во вкладке Actions через Build MatchTrack APK; готовый debug APK будет доступен как artifact. Для этого нужен аккаунт GitHub и загрузка исходников.

Примечания
----------
- Приложение работает офлайн для записей матчей; загрузка рекламы требует интернет.
- Данные пока хранятся локально на конкретном устройстве и не синхронизируются между телефонами.
- HLTV Rating 2.1 можно ввести вручную; точный рейтинг нельзя достоверно вычислить только из K/D/A и урона.
- Перед публикацией в Google Play нужно проверить требования текущей версии Play Console, политику рекламы, целевую версию Android и политику конфиденциальности.
